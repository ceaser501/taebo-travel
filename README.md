# 도쿄 태교여행

둘이 함께 쓰는 도쿄 태교여행 앱입니다. 홈 화면에 추가해서 앱처럼 쓰는 웹앱(PWA)이에요.

- **일정 · 지도**: 날짜별 동선 지도와 번호 핀, 이동 수단과 구글 지도 길찾기
- **일본어**: 장소마다 간판에 쓰인 일본어·읽는 법·뜻, 발음 듣기, 크게 보여주기, "○○はどこですか?" 묻기
- **티켓 지갑**: 탑승권·입장권 QR 사진이나 PDF를 올려 두고 입구에서 크게 보여주기 (오프라인에서도 열림)
- **기록 · 가계부**: 둘이 같은 기록을 보고, 인터넷이 없을 때 쓴 것은 연결되면 자동으로 맞춰짐

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀 |
| `styles.css` | 디자인 |
| `data.js` | 여행 내용 (장소, 일정, 일본어 간판, 지도 좌표) |
| `sync.js` | 이 기기에 먼저 저장하고 Supabase와 동기화, 파일은 IndexedDB에 보관 |
| `app.js` | 화면과 동작 |
| `sw.js` | 오프라인 캐시 |
| `vendor/` | Supabase JS 2.45.4 (CDN 없이 오프라인에서도 동작하도록 포함) |
| `supabase/` | 서버에 적용한 테이블·권한 기록 |

## 서버

Supabase 프로젝트 `oneteam-vote` 안에 `trip_` 테이블과 비공개 버킷 `trip-files`를 씁니다. 같은 여행에 참여한 사람만 데이터와 파일을 볼 수 있도록 행 단위 보안(RLS)으로 막혀 있어요.

## 배포

GitHub Pages: Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 설정합니다.
